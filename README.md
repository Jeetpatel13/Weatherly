# Weatherly

Weatherly is a responsive weather web application that provides real-time weather updates and forecasts for cities using a weather API. Built with HTML, CSS, and JavaScript, it offers a simple and user-friendly way to check weather conditions.

## Features

- **Real-Time Weather Updates** – Retrieve current weather conditions for a selected city.
- **City-Based Search** – Search for weather information by city name.
- **Weather Forecasts** – View forecasts supported by the integrated weather API.
- **Responsive Design** – Access the application across desktop and mobile devices.

## Technologies Used

- **HTML** – Structures the application content.
- **CSS** – Styles the interface and supports responsive layouts.
- **JavaScript** – Handles user interactions and API requests.
- **Weather API** – Retrieves weather data and forecasts.

## Project Purpose

This project demonstrates front-end web development skills, API integration, and responsive user interface design.
